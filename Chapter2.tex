\chapter{Разработка программного обеспечения для численного моделирования}

Для проведения комплексного численного исследования динамики опухолевых
процессов, формализованных в предыдущей главе, было разработано
специализированное программное обеспечение. Программное обеспечение спроектировано
как инструмент, объединяющий вычислительное ядро, модуль глобальной оптимизации
и интерактивный графический интерфейс для анализа результатов в режиме реального времени.

\section{Обоснование выбора набора используемых технологий и архитектурных решений
программного обеспечения}

Выбор технологического стека обусловлен необходимостью интеграции методов
высокопроизводительных вычислений с гибкими средствами визуализации. В качестве
основного языка реализации выбран Python. Это решение обусловлено развитой
экосистемой научных пакетов:  ядра SciPy (в частности, модуля
  \texttt{scipy.optimize} для автоматической калибровки параметров алгоритмом
  дифференциальной эволюции и \texttt{scipy.integrate} для численного решения
систем ОДУ) и библиотеки NumPy \cite{numpy} для высокопроизводительных
векторных вычислений.
Использование готовых высокоуровневых абстракций имеющихся в этих библиотеках методов
позволяет сосредоточиться на проектировании специфической логики приложения,
такой как архитектура вычислительного ядра, алгоритмы автоматизированного
управления терапевтическими воздействиями и интерфейсы для симуляции
клинических сценариев.

Математический фундамент системы реализован на базе пакета SciPy \cite{scipy}, в частности
модуля \texttt{integrate}. Для решения систем обыкновенных дифференциальных
уравнений в данной работе был использован метод Дормана-Принса (RK45)
\cite{dormand_prince}. В отличие от численного метода Рунге-Кутты 4-го порядка
с фиксированным шагом, метод Дормана-Принса обеспечивает адаптивность шага
интегрирования, что позволяет достичь оптимального баланса между точностью и
производительностью.

Для построения графического интерфейса использовался фреймворк PyQt.
Он обладает возможностью создания приложений на основе
событийно-ориентированной архитектуры \cite{oop}. На этой основе в приложении
реализован блок интерактивных слайдеров (ползунков): при изменении положения
слайдера генерируется сигнал, передающий новое численное значение параметра
напрямую в вычислительное ядро системы. Это обеспечивает мгновенный
динамический пересчет и обновление модельных кривых на экране.

Визуализация расчетных графиков встроена в графический интерфейс приложения с
использованием библиотеки Matplotlib \cite{matplotlib}. Данное решение
обеспечивает интерактивное управление осями координат, а также предоставляет
встроенный инструментарий для масштабирования и панорамирования расчетных
траекторий.

\section{Проектирование интерфейса и логики работы программного обеспечения}

Графический интерфейс разработанного программного обеспечения реализован на базе
многовкладочной архитектуры, что позволяет разграничить задачи визуализации решения
системы дифференциальных уравнений математической модели и анализа
чувствительности параметров данной модели. Основное окно приложения
(рисунок \ref{fig:gui_layout}) включает вкладку <<Визуализация модели>>,
предназначенную для интерактивного исследования динамики системы.

\subsection{Проектирование пользовательского интерфейса программного обеспечения}

В основу графического интерфейса программного обеспечения легла многовкладочная
архитектура. Такое разделение позволило изолировать вычислительные задачи по
расчету дифференциальных уравнений от процедур, связанных с анализом
чувствительности параметров. Главное окно разработанного приложения (рисунок
\ref{fig:gui_layout}) содержит стартовую вкладку <<Визуализация модели>> -- именно
она отвечает за интерактивный мониторинг и исследование динамики системы в
реальном времени.

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{gui_layout.png}
  \caption{Графический интерфейс программного обеспечения (вкладка визуализации модели)}
  \label{fig:gui_layout}
\end{figure}

Справа от холста визуализации скомпонована панель управления. В неё вынесены
блоки начальных условий ($T_0, I_0, C_0, t_{end}$) и коэффициентов модели ($a,
b, c, \mu, d, p, \lambda$), выполненные в виде интерактивных слайдеров. Сдвиг
любого регулятора мгновенно запускает повторное интегрирование системы ОДУ,
после чего графики на главном экране перестраиваются в логарифмическом
масштабе. Помимо расчетных кривых, программный модуль позволяет накладывать на
оси реальные клинические данные, автоматически отображая доверительные
интервалы и вычисляя коэффициент детерминации $R^2$ для оценки адекватности модели.

Для проведения пакетных вычислительных экспериментов спроектирована вторая
вкладка интерфейса -- <<Параметрический анализ>> (рисунок \ref{fig:gui_layout_2}).
Архитектура этой панели проектировалась с целью управления интервалами варьирования
констант. Через доступные элементы интерфейса пользователь задает границы
изменения и шаг для выбранного параметра, после чего система автоматически
формирует расчетную сетку и запускает серию симуляций.

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{gui_layout_2.png}
  \caption{Графический интерфейс программного обеспечения (вкладка
  параметрического анализа)}
  \label{fig:gui_layout_2}
\end{figure}

Окно вывода графики на данной вкладке функционирует в двух режимах: одномерного
и двумерного параметрического анализа. В рамках одномерного исследования
варьируется только одна выбранная изолированная константа при жесткой фиксации
всех остальных коэффициентов, что позволяет оценить чувствительность
математической модели к изменению величины одного выбранного параметра. При
выборе двумерного параметрического анализа происходит одновременное измененние
двух параметров по заданной расчетной сетке. Метрика, которая была выбрана для
оценки результатов такого анализа для каждого набора величин выбранных параметров,
отображается значением, соответствующим цвету по шкале этой метрики, указанной
в правой части окна возле результирующего двумерного графика (тепловой карты).
Такой анализ позволяет выявить область значений выбранных параметров, при
которых поведение системы отражает положительную динамику развития опухоли, а
также определить область значений этих параметров, при которых исход результат
течения заболевания будет неблагоприятным. Выявление таких областей значений
параметров позволяет определить их влияние на исход развития опухоли при
отсутствии терапии.

\subsection{Диаграмма основных сценариев функционирования разработанного
программного обеспечения}

Взаимодействие пользователя с основными компонентами программного обеспечения
отражено на рисунке \ref{fig:uml_sequence}. Данная UML-диаграмма
последовательности отражает 2 основных сценария взаимодействия между
пользователем и программой: проведение симуляции (численное решение на основе
выбранных значений параметров) и проведение параметрического анализа. Она
иллюстрирует механизмы обмена сообщениями между тремя ключевыми сущностями:
Пользователем (Actor), Графическим интерфейсом (GUI на базе PyQt5) и
Вычислительным ядром (Solver на базе SciPy).

\begin{figure}[ht!]
  \centering
  \includegraphics[width=0.9\textwidth]{fig/uml_sequence.png}
  \caption{Диаграмма последовательности основных сценариев работы:
  симуляция и параметрический анализ.}
  \label{fig:uml_sequence}
\end{figure}

Первый сценарий взаимодействия -- интерактивная симуляция -- запускается
при смещении пользователем любого слайдера, соответствующего одному из
параметров математической модели, или при смене режима терапевтического
воздействия. После этого графический интерфейс генерирует сигнал, который
передается в блок вычислений программы, в результате работы которого происходит
повторное интегрирование системы ОДУ с новыми значениями параметров.
Полученный набор данных используется впоследствии для обновления графиков
популяционной динамики.

Второй сценарий взаимодействия -- проведение параметрического анализа системы.
После выбора пользователем варьируемых при анализе параметров системы, а также
установки границ значений выбранного параметра и шага по временной расчетной сетке
производится многократный процесс симуляции с известными наборами параметров.
В результате формируется набор кривых, описывающих динамику концентрации
опухолевых клеток, соответствующих каждому узлу расчетной сетки, а также текущему
значению варьируемого параметра. После чего происходит обновление графиков,
отображающих результаты параметрического анализа, которые показывают, как
изменение конкретного параметра влияет на динамику системы.

\section{Алгоритм идентификации параметров модели на основе метода
дифференциальной эволюции}

Задачу идентификации параметров скорости активации иммунных клеток и
скорости уничтожения опухолевых клеток решает алгоритм дифференциальной эволюции
\cite{diff_evo}. Данный стохастический метод глобальной оптимизации был выбран
благодаря своей способности эффективно исследовать многомерные пространства
параметров, избегая локальные экстремумы исследуемой системы.

Функционирование данного модуля в структуре вычислительного ядра (рисунок
\ref{fig:de_flowchart}) опирается на эволюционную парадигму минимизации целевой
функции потерь \cite{rmse}. На начальном этапе система создает начальный
набор векторов, каждый из которых представляет собой уникальный набор
искомых коэффициентов, при этом генерация жестко ограничивается установленными
рамками допустимых значений параметров. Дальнейший расчет организован как итерационный
цикл смены поколений, который выполняется вплоть до срабатывания критерия
останова или достижения заданного порога точности аппроксимации.

\begin{figure}[ht!]
  \centering
  \includegraphics[width=0.4\textwidth]{fig/de_flowchart.png}
  \caption{Блок-схема алгоритма дифференциальной эволюции для калибровки
  параметров модели.}
  \label{fig:de_flowchart}
\end{figure}

На каждой итерации алгоритма текущий набор векторов подвергается процедурам
мутации и кроссовера. Мутантный вектор формируется за счет линейного
комбинирования случайно выбранных донорских элементов и масштабирования их
разности с помощью дифференциального веса $F$. На основе полученной структуры
затем создается пробный вектор $U$. Ключевое звено алгоритма -- процедура
оценки функции приспособленности (фитнес-функции): вычислительный блок
запускает численное интегрирование системы ОДУ со значениями параметров из
вектора $U$, после чего рассчитывает среднеквадратичную ошибку ($MSE$) по
отношению к опорным клиническим данным.

Завершается итерационный цикл процедурой выбора, основанной на сравнении
значений целевой функции пробного вектора $f(U)$ и исходного вектора $f(X_i)$.
В случае если сгенерированный набор параметров демонстрирует меньшую или равную
ошибку аппроксимации, он замещает прежний элемент в популяции нового поколения.
При обратном исходе вектор $X_i$ сохраняется без изменений. Описанная
циклическая процедура позволяет автоматизировать процесс подбора оптимальных
значений варьируемых параметров модели. Это обеспечивает физическую
интерпретируемость коэффициентов и позволяет адаптировать фундаментальную
систему уравнений для персонализации клинических сценариев.
